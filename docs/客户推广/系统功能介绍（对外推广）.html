01
🗂️

基础数据统一管理

部门、人员、物资分类、物资、库位、供应商一次录入全校共用；记录停用而非删除，历史全程可追溯。

02
📊

库存与固定资产

耗材实时可用量、库位、批次一目了然；固定资产一卡一档、责任到人，资产号与二维码随机生成。

03
🧾

业务单据全流程

入库 / 出库 / 报损 / 调整四类单据，申请→审批→执行受控流转；每张单据带幂等键，重复提交不重复记账。

04
📷

扫码领用（核心亮点）

教师用微信或手机相机扫物资二维码，一键确认即完成领用；无需登录也可轻量领取，防刷、防冒领。

05
📱

移动查库存

手机浏览器随时查看物资库存与"有货 / 不足"提示，不必守在电脑前。

06
🏷️

二维码标签

管理员一键为物资生成二维码标签（PNG），打印张贴，供扫码领用与盘点使用。

07
🛒

请购与审批

教师在线提交请购，总务主任在线批准 / 驳回；批准后采购入库，库存自动增加并自动通知申请人。

08
🔔

站内通知

审批结果、到货入库等关键节点自动推送站内消息（导航栏铃铛未读提示），可标记已读。

09
🔧

报修工单

师生在线报修（对象、描述、优先级、照片），派单→维修→完成 / 取消全程记录，进度随时可查。

10
🛡️

证据附件与审计

处置单图片 / PDF 可上传、关联、撤回、保全；私有加密存储，保留期可配置，满足审计留痕。

安全与合规（给您一颗定心丸）
面向学校场景设计，隐私保护与权限管控是底层能力而非附加项。
  • ✓数据隔离：每所学校数据独立隔离，互不越界。
  • ✓敏感信息加密：供应商联系人等敏感字段应用层加密，仅授权角色可见。
  • ✓角色权限分明：管理员 / 普通用户分级，审批禁止自批并留审计。
  • ✓会话族机制：改密、禁用、重置密码即全局登出，防止账号蹭用。
  • ✓防护到位：登录限流、防重放、严格 CSP 策略，抵御常见攻击。
  • ✓内置对账：13 项一致性校验，账目长期可信。
