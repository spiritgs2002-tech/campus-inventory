# 校园总务 · 库存与资产管理系统 — 功能介绍

> 适用对象：学校总务处，以及任何需要管理物资、固定资产、领用与维修流程的单位。
> 本文档用于对外介绍与推广，帮助您快速了解系统能做什么、能解决什么问题。
> 技术细节与操作步骤请参阅随附的《使用手册》《云端部署与上线测试执行手册》。

---

## 一、系统定位（一句话）

把学校总务处"**物资进了哪、谁领了什么、缺了怎么买、坏了怎么修**"全部搬上系统——
让管理可追溯，让师生少跑腿。

## 二、您正面临的麻烦，系统怎么解决

| 传统做法的麻烦 | 系统带来的改变 |
|---|---|
| 领用靠纸质签字、月底对账费时 | 领用线上登记、库存实时更新、台账自动生成 |
| 不知道仓库还有多少、该不该买 | 库存不足自动提示；教师可直接发起请购 |
| 资产卡片散落、盘点靠纸面 | 固定资产一卡一档、二维码标签、扫码即查 |
| 物品坏了口头报修、进度没下文 | 在线报修工单、派单处理、进度可查 |
| 敏感信息（学生/联系人）容易泄露 | 数据按校隔离、敏感字段加密、权限分明 |

## 三、功能全景

### 1. 基础数据统一管理
部门、人员、物资分类、物资、库位、供应商，一次录入、全校共用。记录**停用而非删除**，任何历史都可追溯。

### 2. 库存与固定资产
- **耗材库存**：实时可用量、库位、批次一目了然；低于安全库存自动提示不足。
- **固定资产**：一卡一档，责任到人；资产编号系统统一分配；资产号与二维码随机生成。
- **资产维修跟踪**：在库 ↔ 维修中状态切换，维修原因留痕。

### 3. 业务单据全流程
| 单据类型 | 包括 | 关键特点 |
|---|---|---|
| 入库 | 采购 / 开班 / 退货 | 即时生效、不可取消；采购必填供应商 |
| 出库 | 领用 / 退库 / 转移 | 申请 → 审批 → 领取，本人领用 |
| 报损 | 报损 / 遗失 / 找回 / 损坏 | 流程受控、证据留痕 |
| 调整 | 盘点 / 质量转换 | 管理员复核账面数量与版本 |

每张单据都带**幂等键**，网络抖动时重复提交不会重复记账。

### 4. 扫码领用（核心亮点）
教师用微信或手机相机扫一下物资上的二维码，打开领用页，**一键确认即完成领用登记**——
- 无需登录也可轻量领取，归属仍记本人；
- 同一二维码短时间内重复扫只登记一次，**防刷、防冒领**；
- 正式领取建议先登录，便于追溯与统计。

### 5. 移动查库存
手机浏览器即可随时查看物资库存与"有货 / 不足"提示，不必守在电脑前。

### 6. 二维码标签
管理员一键为物资生成二维码标签（PNG 图片），打印张贴，供扫码领用与盘点使用。

### 7. 请购与审批
- 教师发现缺货，在线提交**请购申请**（物品、数量、说明）；
- 总务处主任在线**审批**：批准或驳回；
- 批准后由管理员**采购入库**，库存自动增加，并**自动通知**申请人。

### 8. 站内通知
审批结果、到货入库等关键节点，申请人自动收到**站内消息**（导航栏铃铛显示未读数），点击即可查看，可标记已读。

### 9. 报修工单
- 师生在线提交报修（报修对象类型、描述、**优先级**、可附照片）；
- 总务处在线**派单 → 开始维修 → 完成 / 取消**，状态全程记录；
- 申请人随时查看自己工单的处理进度。

### 10. 证据附件与审计
处置单相关的图片 / PDF 可上传、关联、撤回、保全；对象存于私有加密存储；保留期可配置，满足审计留痕要求。

## 四、安全与合规（给您一颗定心丸）

- **数据隔离**：每所学校数据独立隔离，互不越界；
- **敏感信息加密**：供应商联系人等敏感字段应用层加密，仅授权角色可见；
- **角色权限分明**：管理员 / 普通用户分级，审批禁止自批并留审计；
- **会话族机制**：改密、禁用、重置密码即全局登出，防止账号蹭用；
- **防护到位**：登录限流、防重放、严格的 CSP 策略，抵御常见攻击；
- **内置对账**：13 项一致性校验，账目长期可信。

## 五、一个典型的工作日

> 早上，总务处打印好新到物资的二维码标签并张贴；
> 上午，李老师扫码领走两盒打印纸，库存实时减少；
> 中午，王老师发现粉笔不够，提交一份请购；
> 主任午休时用手机审批通过，管理员下午采购入库，系统**自动通知**王老师来领；
> 下午，某班门锁损坏，学生在系统提交报修工单，总务处派单维修并标记完成。
>
> 全天每一笔操作，都有据可查。

## 六、技术特点（给 IT 同事）

- **成熟稳定**：Python / Django + PostgreSQL + Redis 技术栈；前端响应式，电脑与手机都能用。
- **自主可控**：支持私有化部署（云服务器或单位内网），数据掌握在自己手里。
- **可交付可运维**：提供部署手册与上线验证流程，支持平滑迁移、备份与回滚。
- **质量保障**：已在真实 PostgreSQL 16 环境通过完整自动化测试（**266 项**）与多项集成校验。
