# 本地部署骨架实测报告（Local Bootstrap Smoke Test）

- 测试对象：`inventory-v4/django` 部署骨架（应用启动 + 数据库 bootstrap 链路）
- 测试时间：2026-10-31
- 测试人：控制中枢（独立，非 Codex 自报）
- 测试环境：本机隔离 PG16 集群（端口 55432）。**本机缺 docker / nginx / redis-server**，故容器编排、nginx 服务、真实 Redis、真实云 S3 未测（见 §4 交还项）。

---

## 1. 实测脚本

`/tmp/local_bootstrap_smoke.sh`（可复现，用户可在目标环境改 host/密码复用）：
1. 模拟 DBA：建迁移身份 `inventory_app`（CREATEDB CREATEROLE）+ 运行身份 `inv_run`（inventory_runtime 成员）+ `inventory_runtime`（NOLOGIN），并建 `campus_inventory` 库（OWNER inventory_app）。
2. `apply_schema`（迁移身份）→ `verify_schema` → `verify_runtime`（运行身份）。
3. `provision_tenant`（首个租户 + 管理员）。
4. `collectstatic` / `check --deploy`。
5. gunicorn 启动 + 探活；Django test client 确定性验证。
