## 1. 项目概况
- **技术栈**：Python 3.13 + Django 5 + PostgreSQL 16 + psycopg3；Celery + Redis；前端 Django Templates + Alpine + HTMX + Bootstrap 5。
- **模块归属**：库存/资产模块归入校园 SaaS（总务域），代码位于 `apps/asset`。
- **数据库权威**：`schema-v7.sql` 为唯一 SQL 规则来源（27 表 / 14 函数 / 32 触发器，真实 PG16.15 实测 G0 通过）。Django 仅作 ORM 读写外壳，DDL/触发器/函数/授权严禁 autogenerate，须手写 RunSQL。
- **合规红线**：初中生属敏感个人信息，严禁公开成绩排名。
