# P6 上线前配置事项

P6 本地代码与测试已完成，以下是实际部署配置，不是待修复代码，也不代表已完成云端/学校验收。

1. 学校确认附件保留政策，运维设置 `ATTACHMENT_RETENTION_DAYS`。当前无默认值；测试的30天仅为合成场景，未确认时不要启用证据清理。
2. 配置私有 S3/S3 兼容桶、区域、HTTPS 端点及受限服务身份；凭证使用环境或 IAM。验证真实云端上传、条件写、读回校验、未授权拒绝和服务端加密。证据前缀不得使用普通导出对象的7天清理生命周期。
3. 配置正式 Redis 地址、网络隔离及凭证，启动 Celery worker。不得把测试脚本中的合成 AWS key 或临时对象服务用于生产。
4. 将嵌套 CI 工作流按实际仓库布局放到可发现位置并执行远端 CI；本次只报告本地实际运行结果。
5. P7 再实现和验收对账调度、对象清理/补偿及终局流程；当前没有开启物理删证据、缩短保留期或解除 legal_hold 的业务接口。

本地开发若不连接云端，可在 DEBUG=true 时显式使用私有 filesystem 目录；它不是正式云端验收的替代。
